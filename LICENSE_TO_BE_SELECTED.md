# License to be selected before public release

Before making this repository public or citing it in a manuscript, the research team should explicitly choose:

1. A code license, such as MIT, BSD-3-Clause, Apache-2.0, or GPL-3.0.
2. A data license or data-access statement, such as CC BY 4.0, CC BY-NC 4.0, or controlled access only.

Because the repository contains human-subject survey data, even in de-identified form, the data sharing terms should be checked against the ethics approval, participant information/consent language, and institutional data-sharing rules.
