# Data notes

This folder contains the de-identified tabular dataset used for the pilot survey analysis.

- `raw/survey_responses_deidentified.csv`: manually digitized responses from the structured evaluation forms. Direct identifiers are not included.
- `processed/survey_responses_derived.csv`: analysis-ready dataset with binary indicators derived from the raw responses. This file can be regenerated by running `scripts/02_derive_variables.py`.
- `metadata/codebook.csv`: variable-level codebook.
- `metadata/coding_notes.txt`: notes on ambiguous or unusual source-form markings retained during manual coding.

The scanned original forms are intentionally excluded from this repository because they may contain handwritten notes or contextual information that should not be publicly redistributed.
