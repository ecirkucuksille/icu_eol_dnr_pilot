# DATA AND ANALYSIS CODE AVAILABILITY

The de-identified tabular dataset, a complete data dictionary, and the Python analysis code are publicly available at https://github.com/ecirkucuksille/icu_eol_dnr_pilot. The data dictionary documents all raw and derived variables, response codes, variable derivation rules, and missing-value conventions. The repository also includes reproducible result tables and figures, coding notes, and a manuscript–analysis consistency report. The code reproduces the descriptive analyses, Fisher exact tests with Holm adjustment, supplementary Firth penalized logistic regression models, and coding sensitivity analyses reported in the article and supplementary material. Scanned completed questionnaires and participants’ handwritten annotations are not publicly shared.
