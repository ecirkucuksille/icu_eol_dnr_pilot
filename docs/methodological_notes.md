# Methodological notes

This repository accompanies a pilot cross-sectional survey on end-of-life decisions, do-not-resuscitate decisions, legal confidence, and procedural solution expectations among physicians involved in intensive care practice.

## Reporting framework

The manuscript is structured according to the STROBE framework for observational studies, particularly the cross-sectional study checklist.

## Small-sample analysis rationale

The dataset contains 28 participants. For this reason, inferential analyses are treated as exploratory rather than confirmatory. Fisher's exact test is used for 2x2 categorical comparisons, and Firth penalized logistic regression is used for pilot logistic models because sparse cells and separation can make standard maximum-likelihood logistic regression unstable.

## Reproducibility principles

The repository follows a transparent project structure with separate folders for raw data, processed data, scripts, outputs, and documentation. This structure is consistent with good-enough scientific computing practice and FAIR-oriented data stewardship.

## Privacy note

The public repository should include only de-identified tabular data. The scanned questionnaires should not be released unless the research team has verified that no personal or institutionally sensitive information remains visible and that public release is covered by ethics approval and participant consent.
